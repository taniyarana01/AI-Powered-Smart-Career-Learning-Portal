# AI-Powered Smart Career Learning Portal

This is a full-stack web application built using the MERN stack. I built this project to help students and job seekers learn new skills, prepare for interviews, create professional resumes, and improve their career journey with the help of AI.

The platform brings different AI tools together in one place so users can learn, practice, build resumes, and get career guidance more easily.

---

## Features

### AI Features

- AI Smart Notes Generator
- AI Tutor
- AI Mock Interview
- AI Resume Builder
- ATS Resume Analyzer
- AI Skill Tracking
- Resume Improvement Suggestions
- AI Job Recommendations

### Learning Features

- Career Roadmaps
- Learning Resources
- Personalized Dashboard

### Resume Features

- Create Professional Resume
- Upload Resume (PDF/DOCX)
- ATS Compatibility Check
- Resume Score
- Skill Gap Analysis

### User Features

- User Authentication (JWT)
- Profile Management
- Responsive Design

## Installation

Clone the repository

```bash
git clone https://github.com/taniyarana01/AI-Powered-Smart-Career-Learning-Portal.git
```

Install frontend

```bash
cd frontend
npm install
npm run dev
```

Install backend

```bash
cd backend
npm install
npm start
```

---

## Environment Variables

Create a `.env` file inside the backend folder.

```env
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_api_key
```
